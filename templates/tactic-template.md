## Txxxx(.xxx) ชื่อ Technique

**วิธีทำงาน** — ผู้โจมตีทำอย่างไร ใช้เครื่องมือ/กลไกอะไร (ระดับแนวคิด ไม่ต้องให้ขั้นตอนโจมตีที่ใช้ได้ทันที)

**สัญญาณ**
- สิ่งที่มองเห็นได้ใน log

**KQL — สิ่งที่ query นี้จับ**
```kql
TableName
| where Timestamp > ago(1d)
| where ...
| project ...
```

**สิ่งที่ต้องปรับ** — threshold, allowlist, ชื่อเครื่อง/subnet ขององค์กร

**วิธีรับมือ**
1. Triage
2. Scope
3. Contain
4. Eradicate / Recover

**ป้องกันระยะยาว** — Mitigation (Mxxxx) และการตั้งค่าที่ทำได้จริง

**False positive** — กรณีที่ถูกต้องตามธุรกิจที่มักทำให้ query แจ้งเตือน
